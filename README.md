# 🏝️ Ben The Adventurer: 1,000 Levels Mobile Platformer

A kid-friendly 16:9 landscape action-platformer and adventure game built with **Phaser 3 / HTML5** (Web) and **Kotlin & Jetpack Compose** (Android).

---

## 🎮 Game Features

- **1,000 Sequential Levels across 5 Locked Biomes:**
  - 🌿 **Levels 1–200:** Emerald Grasslands
  - 🍬 **Levels 201–400:** Candy Kingdom
  - ☁️ **Levels 401–600:** Sky Castle
  - 🏜️ **Levels 601–800:** Desert Oasis
  - 🌋 **Levels 801–1000:** Lava Citadel
- **Boss Arena Battles (Milestones 200, 400, 600, 800, 1000):**
  - Requires 50 hits with visible Boss Health Bar.
  - Princess Clara rescue sequence with victory melody.
- **Permanent Power-Up Swapping System:**
  - Fireball Blaster 🔥
  - Ice Beam ❄️
  - Laser Spread ⚡
  - Rapid Machine Gun 💥
- **Retro 8-Bit Web Audio Synthesizer:**
  - Built-in zero-dependency procedural chiptune sound effects.
